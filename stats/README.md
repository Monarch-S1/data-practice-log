# Statistics

Concepts from the IBM SkillsBuild statistics course, applied to real data the same day
they are learned. A concept without an application does not stick.

Order: descriptive stats → distributions → sampling → confidence intervals →
hypothesis testing → correlation vs causation → regression basics.

Every notebook or script here answers a real question, ideally a logistics one.
"Is this lead-time difference between two carriers real, or is it noise?" beats
any textbook exercise.
